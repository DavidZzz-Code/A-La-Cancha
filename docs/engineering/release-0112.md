# Android 0.1.12 (13)

La reserva confirmada por el servidor abre una pantalla con animación, horario y acceso a Google Maps. Una entrada verificada abre indicaciones a sus coordenadas. Una sede pendiente de verificar abre una búsqueda por nombre y dirección. Próximas e Historial comparten la tarjeta de partido y mantienen los cambios de horario y las reseñas en el detalle.

Las cuatro sedes de Cartagena tienen portadas ilustradas hasta recibir fotos propias o autorizadas. La galería y las reseñas se consultan por separado. Se muestra el conteo real y se mantiene la aprobación simulada del anticipo durante el piloto.

Android 0.1.13 (14) incorpora cuatro imágenes generadas con IA para el piloto. Cada portada lleva la etiqueta «Imagen ilustrativa». Una foto del propietario tiene prioridad en la ficha, el catálogo y la reserva.
