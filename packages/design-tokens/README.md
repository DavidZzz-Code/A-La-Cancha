# Valores de diseño compartidos

Estado: dirección visual propuesta; valores definitivos pendientes de validar.

Centralizar colores semánticos, tipografía, espaciado, bordes y duraciones de movimiento. Usar nombres como `background`, `textPrimary` y `actionPrimary`, evitando copiar colores sueltos por pantalla.

Compartir valores entre móvil y web, sin obligar a compartir componentes con comportamientos diferentes. Ver [dirección visual](../../docs/design/direction.md).
