# Valores de diseño compartidos

src/index.ts centraliza la paleta verde/lima, fondos, colores de texto y nombres de Manrope/Space Grotesk. La app incluye esas fuentes como dependencias locales y utiliza ilustraciones SVG propias.

El diseño implementado es una primera propuesta pendiente de validación con jugadores. Espaciado, radios y componentes se podrán consolidar al estabilizar patrones reales de uso. Ver [dirección visual](../../docs/design/direction.md) y [capturas](../../docs/design/previews/).
